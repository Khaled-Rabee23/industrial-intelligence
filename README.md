# Industrial Intelligence Platform

A responsive, standalone website mockup with separate HTML, CSS, and JavaScript files.

## Files

- `index.html` — page structure and content.
- `style.css` — all visual styling and responsive layouts.
- `script.js` — interactive ranking filters and country comparison.
- `README.md` — this guide.
- `.gitignore` — common local files excluded from Git.

## Run locally

No dependencies or build tools are required. Keep all files in the same folder and open `index.html` in a modern browser.

Alternatively, run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## GitHub Pages

Upload the contents of this folder to the root of a GitHub repository. Then open **Settings → Pages**, select **Deploy from a branch**, choose your main branch and `/(root)`, and save.

## Data disclaimer

All country rankings, scores, comparison values, and tournament matchups are illustrative placeholders, not verified industrial statistics. Replace them with sourced data before public or policy use.
